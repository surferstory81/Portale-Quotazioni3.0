# Software Licensing Costs

This file contains typical licensing costs for common software components.

## Database Systems

### PostgreSQL
- Open Source: €0 (community support)
- Enterprise support: €2,000-5,000/year

### Oracle Database
- Standard Edition: €17,500/processor (perpetual)
- Enterprise Edition: €47,500/processor (perpetual)
- Annual support: 22% of license cost

### Microsoft SQL Server
- Standard Edition: €3,500-4,000/core
- Enterprise Edition: €14,000-16,000/core
- Software Assurance: 25% annually

## Application Servers

### Wildfly/JBoss
- Community (Wildfly): €0
- Red Hat JBoss EAP: €10,000-15,000/year per 16 cores

### WebSphere
- Base Edition: €7,000-10,000/PVU
- Network Deployment: €15,000-20,000/PVU

## Message Brokers

### RabbitMQ
- Open Source: €0
- VMware Tanzu RabbitMQ: €3,000-6,000/year

### IBM MQ
- €5,000-10,000/PVU (perpetual)
- Annual support: 20% of license cost

## Monitoring and APM

### Dynatrace (CA Real Pricing - See field-to-cost-mapping.md)

- Full Stack: €39.79/GB RAM/anno

- K8s Platform: €14.86/POD/anno
- Logs: €741.16/GB/anno

**DO NOT use generic €0.08/hour pricing** - this is obsolete AWS/Azure pricing.

### Datadog

## Security Tools

### Vulnerability Scanning
- Basic: €50-100/host/month
- Advanced: €150-300/host/month

### WAF (Web Application Firewall)
- Cloud-based: €20-50/site/month
