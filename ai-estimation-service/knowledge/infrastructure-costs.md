# Infrastructure Cost Estimates

This file contains baseline cost estimates for various infrastructure components used in cost estimation.

## Cloud Infrastructure (AWS/Azure)

### Compute
- Small VM (2 vCPU, 4GB RAM): €50-80/month
- Medium VM (4 vCPU, 8GB RAM): €100-150/month
- Large VM (8 vCPU, 16GB RAM): €200-300/month

### Storage
- Block storage: €0.10-0.15/GB/month
- Object storage: €0.02-0.03/GB/month

### Database
- Managed PostgreSQL (small): €100-150/month
- Managed PostgreSQL (medium): €200-300/month
- Managed PostgreSQL (large): €400-600/month

### Networking
- Load Balancer: €20-30/month
- NAT Gateway: €30-50/month
- Data Transfer: €0.08-0.12/GB

## On-Premise Infrastructure

### Compute
- Physical server (entry): €3,000-5,000 (one-time)
- Physical server (enterprise): €8,000-15,000 (one-time)
- Annual maintenance: 15-20% of hardware cost

### Storage
- SAN storage: €200-400/TB (one-time)
- NAS storage: €100-200/TB (one-time)

## Licensing

### Operating Systems
- Windows Server: €500-1,000/year per server
- Red Hat Enterprise Linux: €300-600/year per server

### Middleware
- Application server: €2,000-5,000/year
- Message queue: €1,000-3,000/year

## Support and Operations

### Personnel
- Junior DevOps: €35,000-45,000/year
- Senior DevOps: €55,000-75,000/year
- Cloud Architect: €70,000-90,000/year

### Tools and Monitoring
- APM tool: €50-100/host/month
- Log management: €30-70/GB ingested/month
- Security scanning: €100-300/month
